# issue brief prints its sections upside down

`list` already ranks least-urgent-first so the terminal reads bottom-up: what
matters is closest to the cursor, where your eyes already are. `brief` does
not - it prints PROJECT first, so on any repo with a few closed issues the
summary and NEXT scroll off the top and the cursor sits under RECENTLY
RESOLVED, the least urgent section it has.

Print the sections in reverse. Reading up from the prompt gives PROJECT, NEXT,
IN PROGRESS, READY, BLOCKED, RECENTLY RESOLVED, WARNINGS - the order the PRD
asks for, from the end a terminal actually leaves you at. Order inside a
section does not change; the header still comes first in its block.

--json keeps its logical order: nothing scrolls in a parser.

PRD: `docs/PRD/03- Issue-Brief.md`.
