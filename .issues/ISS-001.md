# List View for the Issue Tracker

Running `issue list` should print every issue in the repo as an aligned table.

## Columns

| Column       | Source                        | Notes                        |
| ------------ | ----------------------------- | ---------------------------- |
| `ID`         | frontmatter `id`              | zero-padded, sorts correctly |
| `TITLE`      | the `#` heading               | column auto-sizes to longest |
| `STATUS`     | frontmatter `status`          | `open` or `closed`           |
| `CREATED AT` | frontmatter `created_at`      | local-time ISO 8601          |

## Acceptance criteria

- [x] Reads every `ISS-*.md` in `.issues/`
- [x] Sorted by id
- [x] Skips files that fail to parse
- [x] Prints a helpful message when there are no issues
- [ ] `--status` flag to filter

## Example output

```
ID       TITLE                       STATUS   CREATED AT
ISS-001  List View                   open     2026-09-04T14:04:43+06:00
ISS-002  Issue View command          open     2026-09-04T14:08:22+06:00
```

> **Note:** the title column is measured from the data, so a long title
> widens the column instead of being truncated.
