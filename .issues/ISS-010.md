# render swallows every error including real ones

`issues.py`:

```python
def render(content):
    try:
        console.print(Markdown(content))
    except:
        print("Something Went Wrong")
```

A bare `except` catches everything and prints a message that says nothing.

## This already cost real time

A `UnicodeEncodeError` - the blockquote bar `U+258C` on a cp1252 Windows console -
was hidden behind this handler for two rounds of debugging. The terminal said
`Something Went Wrong` while the actual exception named the exact character and
the exact codec. The fix took one line (`sys.stdout.reconfigure(encoding="utf-8")`)
once the error was visible.

## Fix

Delete the try/except. `console.print` failing means something is genuinely
wrong and the traceback is the useful output.

If a message is wanted, catch the one class that can actually happen and include
the exception:

```python
except UnicodeEncodeError as error:
    print(f"Could not render {id}: {error}")
```

A bare `except` also catches `KeyboardInterrupt`, so Ctrl-C during a long render
prints "Something Went Wrong" instead of exiting.
