# No CI: every POSIX path in this tool has never run

Every test run this project has had was on one Windows machine on one
interpreter. That makes several claims in CLAUDE.md unverified rather than
false:

- `storage.locked` forks on platform. `msvcrt.locking(LK_LOCK)` is mandatory
  and raises after about ten seconds; `fcntl.flock` is advisory and blocks
  forever. Same intent, different semantics, and the `fcntl` branch has never
  executed.
- `test_degraded.py` asserts the six `run_git` paths degrade rather than
  fail, but never against a machine that actually has no git installed.
- `file_by_id` resolves `ISS-001.md` and `iss-001.md` to the same file on
  Windows and to different files on Linux.
- the UTF-8 and LF pinning exists because this machine defaults to cp1252 and
  CRLF. Nothing checks the behaviour on a machine that defaults the other way.

None of these is known to be broken. All of them are unmeasured, and CI is
the cheapest thing that turns the whole list into facts.

## Scope

One `.github/workflows/ci.yml`. `tests/all.py` already exits non-zero on
failure, so this needs no test framework and the no-framework policy stands
untouched.

Matrix: ubuntu, macos and windows against 3.11, 3.12 and 3.13. Plus one job
that installs the built wheel rather than running from the source tree, and
one with git removed from the path.

## Acceptance

- the matrix runs on push and on pull request
- the wheel job proves the README install line is true on a clean machine
- whatever fails is filed rather than fixed inside this issue
