# ISS-056 Work Plan

## Goal

A first contributor has to read 936 lines to learn the loop

## Plan

## Decisions

- The loop is a transcript, not a description. The acceptance asks for
  commands somebody can run, so the middle of the file is one shell block
  from `uv sync` to `issue close`, and the prose around it says only what a
  command cannot.
- CONTRIBUTING links to CLAUDE.md for the architecture and to README for the
  bug-reporting paragraph, and repeats neither. ISS-045 already paid for the
  lesson that two files carrying the same prose is one file that goes stale.
  The one exception is the two house rules from ISS-052 - where to file, and
  that a pull request must not create an issue file - which are stated in a
  line each because a contributor about to open a pull request must not have
  to follow a link to find out they are about to do the wrong thing.
- What a test looks like is shown by pointing at a real one rather than by a
  fresh skeleton. `tests/test_version.py` is the smallest complete example in
  the repo and it cannot go stale, which a snippet pasted here would.

## Discoveries

- Writing the loop out as commands is what caught two false claims in the
  prose around it. A script checked every local link and anchor and then
  asserted the file's own factual claims against the repo: there are three
  runtime dependencies and not two - `tzlocal` as well as `typer` and `rich` -
  and `tests/all.py` is 22 lines rather than the dozen I had written. A
  CONTRIBUTING that is wrong about the dependency list is worse than none,
  because it is the one file a stranger trusts before they can check anything.
- `--commit` is validated against the repository: a sha that is not there is
  exit 1 with nothing written. So the transcript's
  `--commit "$(git rev-parse --short HEAD)"` is load-bearing rather than
  decorative, and a pasted placeholder sha would fail for a first
  contributor. Verified by running the whole loop - create, start, close - in
  a fresh `git init` with the installed entry point, cwd inside that repo.
  Also verified the refusal it documents: `--completed` with no evidence is
  exit 1.
