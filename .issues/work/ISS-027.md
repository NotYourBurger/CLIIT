## Decisions

- The filter lives in `next_issue`, not `actionable()`. `brief` shares
  `ranked_actionable` and orientation must keep showing other people's work.
  test_brief.py passing unchanged is the check on that.
- `claim_issue`'s read-back check (`landed != who`) stays inline. It compares a
  name to a name, not an issue to a name, so `claimable_by` does not fit it and
  wrapping the value in a fake issue to make it fit would be worse.

## Discoveries

- `current_user()` falls back to `git config user.name`, so the "no name
  configured" case cannot be reached by unsetting `$ISSUE_USER` inside the
  test - the repo's own git config answers. The test replaces
  `issues.current_user` for that one assertion instead.
