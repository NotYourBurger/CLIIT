# ISS-055 Work Plan

## Goal

The README is a reference, and a newcomer needs a path

## Plan

- [x] verify it end to end from a directory that has never seen this repo

- [x] check the four stability promises still read exactly as they read before

## Decisions

- The install answer is `uv tool install`, not `uv sync`. `uv sync` needs a
  clone, a checkout to stand in and a uv already present; `uv tool install`
  puts one `issue` on the PATH and works from any directory. Two steps for a
  newcomer instead of four, and it is the same wheel the CI `wheel` job
  already proves runs with no source tree in sight.
- No `pip install cli-issue-tracker` line anywhere until ISS-054 has published
  one. A README that documents an install that 404s is worse than a README
  that documents a longer install that works.
- Headings renamed for what somebody searches for - "Markdown issue tracker",
  "git", "AI coding agents" - and a table of contents added, because 936 lines
  with no index is a document nobody scrolls twice. The renaming stops at
  Non-goals, Stability and File format: those are promises, and a promise
  reworded for search is a promise changed.
- The agent section is assembled from prose already in the file rather than
  written fresh. It was there, spread across `next`, `start`, `--json` and
  `brief`, where somebody arriving with that exact question would never find
  it whole.

## Discoveries

- The GitHub repository is private: `git ls-remote` succeeds with the local
  credentials, an anonymous `curl` of the same URL gets 404. So there is no
  install path that works for a stranger today, by any spelling - and
  `pyproject.toml` already advertises three URLs that resolve to nothing.
  Making the repository public is a prerequisite for ISS-054, and the README
  is only true from the moment it is.
- `cliit` is free on PyPI (the JSON API 404s; the project page
  soft-404s with a 200, which is the check that lies). One less one-way door
  to worry about, and worth reserving before somebody else does.
- `origin/HEAD` is 3b05327 while local HEAD is 4e3e3c8 - the remote is behind
  by whatever this branch has not pushed. Noted, not acted on.
- `uv tool install .` then `issue --version`, `issue init`, `issue create`,
  `issue next` all work in a directory that is not this repo and is not a git
  repo at all. `init` says on stderr that it wrote no agent instructions
  because there is no CLAUDE.md there - which is ISS-044 behaving, and is the
  first line a newcomer sees, so the README says what it means.
