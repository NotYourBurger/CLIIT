## Decisions

- One write, not two: `set_fields([id, "in-progress"], assignee=who or None, quiet=True)` sets
  both fields through the one function that holds the reopen-clearing rule, so a rule
  added there is a rule `start` gets. That is the whole fix; the flags are the door.
- A new flag `--take` rather than widening `--anyway`. The bug is silence, and an agent
  habitually passing `--anyway` for a blocker would keep reassigning mistyped ids
  silently. `--anyway` stays about blockers only.
- `--take` covers both refusals - someone else's, and closed. Taking a closed issue is
  reopening it, and a closed issue owned by alice is one fact to override, not two flags.
