## Decisions

- Seam is `run(init)` in a tmpdir asserting file content, stderr and exit code -
  the one tests/test_plan.py:96 already uses. No new test file: this is the same
  function's behaviour, and a second file would split init's coverage in two.
- The flag writes AGENTS.md rather than offering a choice of the two. It is the
  vendor-neutral name and Claude Code reads it too, so one boolean covers the
  case; a `--agent-file NAME` would be a path argument that writes outside
  .issues/, which is the one thing this command is careful about.

## Discoveries

- `write_rule` read the file once and appended once, so a second block needed
  the read to keep up with the writes. Growing `text` by each block it appends
  is what makes the idempotence check right within a single run, and it is also
  what tells the blank-line separator that a file `--agents` just created has
  nothing above it to separate from.
