# ISS-045 Work Plan

## Goal

AGENTS.md is an untracked stale copy of CLAUDE.md

## Plan

- [x] delete AGENTS.md
- [x] write the answer into CLAUDE.md - this repo keeps CLAUDE.md only
- [x] tests/all.py green

## Decisions

- **Dropped, not kept.** Two prose files saying the same thing is one file that
  drifts; this one already had, by five issues. Keeping it means every future
  change to CLAUDE.md is two edits and a diff nobody runs. `init --agents`
  still writes AGENTS.md for a repo that gives its agents that name - which was
  always the point of ISS-044 - and this repo does not.
- **No `issue check` finding for the two files disagreeing.** It cannot be
  written: CLAUDE.md and AGENTS.md legitimately differ at the top (a heading
  and a line naming Claude Code), so a byte comparison fires on every repo that
  keeps both on purpose, and anything looser is a prose diff. The plan/issue
  check it was compared to asks a question with a yes or no - is there an issue
  beside this plan - and this one has not got one. Deleting the file is the
  check.

## Discoveries

- `write_rule` appends to whichever of the two files exists, so with AGENTS.md
  gone nothing here recreates it: `init` in this repo touches CLAUDE.md alone
  and only `--agents` would bring it back. No .gitignore entry needed - an
  AGENTS.md that appears here later is one somebody asked for.
