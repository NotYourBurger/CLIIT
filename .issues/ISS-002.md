# Issue View command

Running `issue view <id>` should render the stored Markdown file in the terminal.

## Why

The `.md` files are the database *and* the document. Reading one with `cat`
shows raw syntax; `issue view` should show it **formatted**.

## Behaviour

1. Resolve `<id>` to `.issues/<id>.md`
2. Read the file
3. Hand it to `rich.markdown.Markdown`
4. Print via a `Console`

```python
from rich.console import Console
from rich.markdown import Markdown

Console().print(Markdown(content))
```

### Open questions

- Should the frontmatter be hidden, or shown as a header panel?
- What should `issue view ISS-999` print when the file is missing?

---

See also [the rich docs](https://rich.readthedocs.io/en/stable/markdown.html)
for the supported subset. Nested lists, tables, code fences and block quotes
all render; raw HTML does not.
