# Nothing says where an outsider files a bug

`pyproject.toml` points strangers at GitHub Issues. The backlog is 51 files in
`.issues/`. Neither document says which one an outside report belongs in, and
the first person to arrive has to guess.

The guess is not harmless in either direction. A GitHub issue nobody mirrors
is a report that vanishes; a `.issues/ISS-NNN.md` written in a stranger's pull
request allocates an id off a fork that has no idea what trunk allocated, so
two strangers open two ISS-052s and `reserve_id`'s O_EXCL never sees either of
them.

A mirror in both directions is the answer that sounds complete and is not: a
stale mirror is worse than no mirror, because it looks authoritative. The
decision is which one is the source of truth. The other one is a door, not a
copy.

## Scope

One paragraph, in README and again in CONTRIBUTING, answering:

- where an outsider reports a bug or asks a question
- whether a pull request may add or edit `.issues/*.md`, and if so how an id
  is allocated without racing trunk
- who moves a report from one side to the other, and when

## Acceptance

- README says where to file, above the fold
- the id-allocation answer is written down rather than left for the first pull
  request to discover
- no mirroring mechanism is built here; if the answer needs one, that is its
  own issue
