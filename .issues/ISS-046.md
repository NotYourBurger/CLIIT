# Nothing says who may use this, or which version they have

`main` is pushed to a GitHub remote with no LICENSE file anywhere in the
tree, which legally reads as all rights reserved: nobody may use it, fork it
or contribute to it. Every other item on the launch list is downstream of
that one file.

pyproject.toml is still the uv template. `description = "Add your description
here"`, no `license`, no `classifiers`, no `urls`. And there is no
`__version__` and no `issue --version` - grep finds neither - so a bug report
from a stranger cannot name the version it came from, and neither can a
maintainer reading it.

## Scope

- LICENSE, MIT or Apache-2.0, whichever the author wants
- pyproject: real description, license, classifiers, urls
- `issue --version` through `importlib.metadata.version`, which is one line
  and adds no dependency
- decide whether the personal email in `authors` is meant to be public

## Acceptance

- LICENSE exists and pyproject names it
- `uv run issue --version` prints the version in pyproject
- a built wheel installs and exposes the `issue` entry point
